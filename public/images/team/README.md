## Yêu cầu ảnh

- **Định dạng**: JPG hoặc PNG
- **Tỷ lệ**: Tốt nhất là ảnh chân dung (portrait) — tỷ lệ ~3:4 hoặc 1:1
- **Kích thước**: Khuyến nghị tối thiểu 400×500px
- **Object position**: Ảnh sẽ được cắt từ phần đầu trở xuống (`object-top`)

## Lưu ý

- Nếu file ảnh không tồn tại, website sẽ tự động hiển thị avatar dự phòng màu gradient
- Không cần restart dev server sau khi thêm ảnh — Next.js tự động nhận diện
